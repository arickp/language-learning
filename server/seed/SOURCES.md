## Contribution rules

1. Record new external sources here with their license, retrieval date, and how they were used.
2. Do not copy proprietary course content, example sentences, lesson ordering, or distinctive curated lists.
3. Prefer independently written translations and examples.
4. Preserve required attribution when a source license requires it.
